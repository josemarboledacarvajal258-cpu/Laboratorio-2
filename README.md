# Laboratorio-2
Este repositorio contienen la app web "Métodos numéricos aplicados a la ingeniería civil", además del desarrollo del Workshop 02.

A continuación se dará el paso a paso de como ejecutar el código para la app:

1. La opción más sencilla para hacerlo es haciendo click en el link que está en la portada de este repositorio.

2. Para ejecutarlo desde una terminal se siguen los siguientes pasos:
  - Ejecución desde PowerShell:
     - Se ejecuta el comando "cd" para cambiar la carpeta de ejecución del código, se copia la dirección de la carpeta "app", ya que está es la que contiene toda la estructura de la app web, la carpeta "app" se encuentra dentro de la carpeta "Laboratorio_2".
     - Una vez copiada la dirección de la carpeta, se copiaran los comandos "python -m streamlit run app.py", o "py -m streamlit run app.py", dependiendo de la versión que se tenga de python uno de los dos comandos servirá.
     - Con esto bastará para que la app se ejecute.
  
   - Ejecución desde CMD:
       - Se repite el proceso de cambiar la carpeta de ejecución del código, ejecutando los comandos "cd" y copiando la dirección de la carpeta "app".
       - Se copiaran los comandos "python -m streamlit run app.py", o "py -m streamlit run app.py", dependiendo de la versión de python uno de los comandos servirá.
       - Con esto bastará para que la app se ejecute.
    
Aunque también se puede ahorrar el paso de ejecutar el comando "cd", abriendo la terminal directamente en la carpeta que contenga los módulos y el main para que la app funcione, es decir, abrir la terminal directamente desde la carpeta "app" dentro de la carpeta "Laboratorio_2", eso se hace seleccionando la carpeta, dar click derecho y seleccionar la opción "abrir terminal" y ejecutar el comando "python -m streamlit run app.py" o "py -m streamlit run app.py".
